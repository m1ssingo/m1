# Стальная мастерская

В M1 SciFi первая сталь приходит из доменной печи Immersive Engineering. Из неё сделай наковальню NTM, пресс и заготовки для моторчиков. Продвинутая схема управления Mekanism понадобится для сборочной машины.

## Наковальня и пресс

1. На железной наковальне найди ковку стальной наковальни. Для одного из рецептов нужны железная наковальня и **10 стальных слитков**. Вверху интерфейса находится ковка, внизу — выбор конструкции из предметов в инвентаре.
2. Собери твердотопливный пресс на верстаке. При установке он занимает **три клетки по высоте**. Нижняя клетка — место, куда ставят предмет.
3. Получи штамп для пластин. На железной наковальне в разделе сборки из плоского железного штампа можно получить **железный штамп для пластин**.
4. В прессе отдельно положи уголь, штамп и стальной слиток. После первого цикла забери стальную пластину. Если топливо есть, а полоска стоит, сначала проверь форму штампа по рецепту в JEI.

## Сборочная машина M1 SciFi

Выбери машину в разделе сборки стальной наковальни. Выбранный рецепт забирает детали из инвентаря при нажатии кнопки.

| Компонент | Количество |
|---|---:|
| Стальной слиток | 8 |
| Медная пластина | 4 |
| <ItemLink id="hbm:motor" /> | 2 |
| <ItemLink id="mekanism:advanced_control_circuit" /> | 2 |

Поставь корпус на свободной площадке и подведи [питание](./power.md). Открой **папку шаблонов**, найди изделие и получи его шаблон. Вставь шаблон в машину, затем загрузи указанные в интерфейсе компоненты. У некоторых изделий есть отдельный вход жидкости, поэтому перед автоматизацией посмотри оба бака.
