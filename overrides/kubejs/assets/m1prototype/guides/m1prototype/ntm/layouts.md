# Карты установки

У большинства больших станков NTM есть **один предмет корпуса**. После установки мод сам занимает соответствующие клетки. Для этих машин карты показывают точку установки, объём и стороны подключения. РБМК собирается из отдельных колонн, а Чикагская поленница из сплошной кладки.

В послойных схемах точка **`@`** — клетка установки на полу. **`Я`** — положение ядра машины после установки. **`■`** — клетка корпуса, **`П`** — клетка с подключением. Направления даны для примера с передней стороной на север. Поворот всего корпуса поворачивает порты вместе с ним.
