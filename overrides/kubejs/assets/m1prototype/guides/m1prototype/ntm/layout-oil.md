# Нефтяные машины

У вышки и станка-качалки разная геометрия. Сначала отметь добывающий чанк, затем оставь указанный объём свободным и поставь предмет корпуса. Прежде чем подключать НПЗ, проверь поступление сырой нефти в отдельный бак.

На НПЗ по очереди подключай выходы и записывай типы продуктов из интерфейса. Для нескольких секций ректификационной колонны задавай тип на нижней секции. [Порядок операций и типы фракций](./production.md)

По горизонтали X увеличивается на восток, Z на юг. Y считается от клетки установки. `@` — поставить корпус, `Я` — ядро, `П` — грань подключения, `■` — занято корпусом. Точка `@` совпадает с ядром у части машин. Пустые клетки отмечены точкой.

## Нефтяная вышка

Предмет `hbm:machine_well`. Габарит **3×10×3** по X×Y×Z. Ядро в `(0, 0, 0)`.


**Y = 0**

| Z / X | -1 | 0 | 1 |
| --- | :-: | :-: | :-: |
| -1 | `■` | · | `■` |
| 0 | · | `@` | · |
| 1 | `■` | · | `■` |

**Y = 1…9**

| Z / X | -1 | 0 | 1 |
| --- | :-: | :-: | :-: |
| -1 | `■` | `■` | `■` |
| 0 | `■` | `■` | `■` |
| 1 | `■` | `■` | `■` |
