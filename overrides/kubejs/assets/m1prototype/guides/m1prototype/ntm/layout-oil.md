# Нефтяные машины

У вышки и станка-качалки разная геометрия. Сначала отметь добывающий чанк, затем оставь указанный объём свободным и поставь предмет корпуса. Прежде чем подключать НПЗ, проверь поступление сырой нефти в отдельный бак.

На НПЗ по очереди подключай выходы и записывай типы продуктов из интерфейса. Для нескольких секций ректификационной колонны задавай тип на нижней секции. [Порядок операций и типы фракций](./production.md)

Габариты указаны по осям X×Y×Z. Координаты ядра отсчитываются от клетки, в которой ставится предмет корпуса.

## Нефтяная вышка

Предмет `hbm:machine_well`. Габарит **3×10×3** по X×Y×Z. Ядро в `(0, 0, 0)`.

## Станок-качалка

Предмет `hbm:machine_pumpjack`. Габарит **7×4×3** по X×Y×Z. Ядро в `(0, 0, 0)`.

## Нефтеперерабатывающий завод

Предмет `hbm:machine_refinery`. Габарит **3×9×3** по X×Y×Z. Ядро в `(0, 0, 1)`.

## Ректификационная колонна

Предмет `hbm:machine_fraction_tower`. Габарит **3×3×3** по X×Y×Z. Ядро в `(0, 0, 1)`.

## Башня каталитического крекинга

Предмет `hbm:machine_catalytic_cracker`. Габарит **6×15×7** по X×Y×Z. Ядро в `(0, 0, 3)`.

## Вакуумный нефтеперерабатывающий завод

Предмет `hbm:machine_vacuum_distill`. Габарит **3×9×3** по X×Y×Z. Ядро в `(0, 0, 1)`.

## Башня гидроразрыва пласта

Предмет `hbm:machine_fracking_tower`. Габарит **7×25×7** по X×Y×Z. Ядро в `(0, 0, 0)`.
