# Мастерская

Найди предмет корпуса в [каталоге](./catalog-processing.md). Освободи нужные клетки по этажам. Затем поставь корпус один раз в точке `@`. Проверь, что ядро появилось на ожидаемом месте.

У сборочной и химической машин входы доступны по нижнему периметру. В примере с генератором кабель подходит спереди по оси X = 0. Для предметов отдельно проверь доступный слот и соответствующий шаблон.

По горизонтали X увеличивается на восток, Z на юг. Y считается от клетки установки. `@` — поставить корпус, `Я` — ядро, `П` — грань подключения, `■` — занято корпусом. Точка `@` совпадает с ядром у части машин. Пустые клетки отмечены точкой.

## Твердотопливный пресс

Предмет `hbm:machine_press`. Габарит **1×3×1** по X×Y×Z. Ядро в `(0, 0, 0)`.


**Y = 0**

| Z / X | 0 |
| --- | :-: |
| 0 | `@` |

**Y = 1…2**

| Z / X | 0 |
| --- | :-: |
| 0 | `■` |


## Сборочная машина

Предмет `hbm:machine_assembly_machine`. Габарит **3×3×3** по X×Y×Z. Ядро в `(0, 0, 1)`.


**Y = 0**

| Z / X | -1 | 0 | 1 |
| --- | :-: | :-: | :-: |
| 0 | `П` | `@` | `П` |
| 1 | `П` | `Я` | `П` |
| 2 | `П` | `П` | `П` |

**Y = 1…2**

| Z / X | -1 | 0 | 1 |
| --- | :-: | :-: | :-: |
| 0 | `■` | `■` | `■` |
| 1 | `■` | `■` | `■` |
