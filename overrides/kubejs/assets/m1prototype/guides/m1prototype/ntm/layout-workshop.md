# Мастерская

Найди предмет корпуса в [каталоге](./catalog-processing.md). Освободи место по указанным габаритам и поставь предмет корпуса. Проверь, где появился интерфейс машины.

У сборочной и химической машин входы доступны по нижнему периметру. В примере с генератором кабель подходит спереди по оси X = 0. Для предметов отдельно проверь доступный слот и соответствующий шаблон.

Габариты указаны по осям X×Y×Z. Координаты ядра отсчитываются от клетки, в которой ставится предмет корпуса.

## Твердотопливный пресс

Предмет `hbm:machine_press`. Габарит **1×3×1** по X×Y×Z. Ядро в `(0, 0, 0)`.

## Сборочная машина

Предмет `hbm:machine_assembly_machine`. Габарит **3×3×3** по X×Y×Z. Ядро в `(0, 0, 1)`.

## Химическая установка

Предмет `hbm:machine_chemical_plant`. Габарит **3×3×3** по X×Y×Z. Ядро в `(0, 0, 1)`.

## Центрифуга

Предмет `hbm:machine_centrifuge`. Габарит **1×4×1** по X×Y×Z. Ядро в `(0, 0, 0)`.

## Рудный окислитель

Предмет `hbm:machine_crystallizer`. Габарит **3×6×3** по X×Y×Z. Ядро в `(0, 0, 1)`.

## Сборочный завод

Предмет `hbm:machine_assembly_factory`. Габарит **5×3×5** по X×Y×Z. Ядро в `(0, 0, 2)`.

## Химический завод 

Предмет `hbm:machine_chemical_factory`. Габарит **5×3×5** по X×Y×Z. Ядро в `(0, 0, 2)`.

## Электрическая дуговая печь

Предмет `hbm:machine_arc_furnace`. Габарит **5×5×6** по X×Y×Z. Ядро в `(0, 0, 2)`.

## Доменная печь

Предмет `hbm:machine_blast_furnace`. Габарит **3×7×3** по X×Y×Z. Ядро в `(0, 0, 1)`.
