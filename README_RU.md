# M1 SciFi Prototype 0.4.0

В 0.4.0 расширены первые две главы и добавлена «Тяжёлая промышленность». В книге три главы и 43 задания, из них 20 дополнительных. Платформа сборки — Minecraft 1.21.1, NeoForge 21.1.267, Java 21 и CurseForge. Новый сервер создаёт отдельный мир `prototype_world` в режиме выживания.

Порядок обновления 0.3.1 и краткие заметки находятся в `docs/UPDATE_0.4.0_RU.md`. Ход разработки и границы проверенного описаны в `docs/STATUS_RU.md`.

В 0.3.1 исправлен экран ошибки входа при HTML-ответе службы сессий. Для профиля 0.3.0 достаточно заменить один клиентский JAR по инструкции `docs/HOTFIX_0.3.1_RU.md`. При переходе с 0.2.0 также используйте `docs/UPDATE_0.3.0_RU.md`.

## Клиент — CurseForge

1. Распакуйте этот общий архив в отдельную папку, например `D:\Minecraft\M1-Prototype-0.4.0`. **Вложенный ZIP из `client` передайте CurseForge целиком.**
2. В CurseForge откройте Minecraft → создание/импорт профиля → импорт из ZIP. Выберите `client/M1-SciFi-Prototype-0.4.0-CurseForge.zip` и дождитесь установки. Название кнопки зависит от языка приложения.
3. В настройках профиля задайте **8192 МБ RAM**. Это начальная настройка для ваших 32 ГБ, её ещё предстоит проверить под нагрузкой. Серверу отдельно выделено 5 ГБ.
4. Запустите профиль через CurseForge. Используйте Java 21; штатный подходящий runtime приложения подходит. Первый запуск может быть долгим.
5. На втором ПК импортируйте тот же ZIP с теми же версиями. Не добавляйте пока другие моды и шейдеры.

Импорт содержит 57 файлов CurseForge, мод совместимости и клиентский мод меню. FTB Backups 3 21.1.5 устанавливается и на клиент, и на выделенный сервер. Sodium, StellarView и карты Xaero входят только в клиент.

## Сервер — Windows 11

Откройте PowerShell в папке `server` распакованного комплекта. Прочитайте [Minecraft EULA](https://aka.ms/MinecraftEULA). Следующая команда устанавливает сервер и подтверждает ваше согласие с EULA:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Server.ps1 -AcceptEula
```

Скрипт ищет Java 21 в PATH, JAVA_HOME и стандартном runtime CurseForge. Если Java не нашлась, укажите путь явно:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Server.ps1 -AcceptEula -JavaPath 'C:\Path\To\Java21\bin\java.exe'
```

Можно переиспользовать уже скачанные моды профиля CurseForge, указав `-ClientModsPath 'D:\Path\To\CurseForgeProfile\mods'`: каждый файл всё равно сверяется по SHA-256; недостающие скачиваются отдельно.

После установки запустите `Start-Server.cmd` и дождитесь `Done (...)! For help, type "help"`. При необходимости передайте ему `-JavaPath 'C:\Path\To\Java21\bin\java.exe'` и/или `-MemoryGB 5`.

- На ПК с сервером подключайтесь к `localhost:25565`.
- В локальной сети второй игрок подключается к IPv4-адресу этого ПК и порту 25565. В брандмауэре разрешите входящий TCP 25565 для своей частной сети.
- Из другой сети нужен доступ к TCP 25565 через ваш обычный маршрут/NAT либо игровой VPN; это не настраивается комплектом.
- `online-mode=true`: нужны действующие игровые аккаунты. RCON выключен.
- Для остановки введите `stop` в консоли сервера. Не закрывайте окно во время сохранения.

Сервер устанавливается в `server/server`. Существующие конфиги при повторной установке сохраняются; папку с чужим сервером установщик не использует. Для 0.3.1 достаточно заменить файлы по инструкции `docs/UPDATE_0.4.0_RU.md` в установленном сервере.

## Первая проверка

Войдите на сервер и откройте книгу FTB Quests через кнопку в инвентаре. Для общего журнала заданий соберите одну команду FTB Teams. Глава начинается с молота и руководства IE. На вехе «Открытие электроники» возьмите награду исследования, чтобы сервер открыл рецепты для обоих игроков.

Администратор может проверить текущее состояние командой `m1probe` в консоли. Команды ручного закрытия и открытия приведены в `docs/TEST_PROTOCOL_RU.md`. Для прохождения главы пользуйтесь книжкой квестов и JEI.

Серверную часть 0.4.0 проверили на Linux. При сбое графического клиента пришлите его `logs/latest.log` и `server/server/logs/latest.log`, если сбой произошёл при подключении.
