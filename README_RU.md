# M1 SciFi Prototype 0.8.1

В 0.8.1 девять глав и 239 заданий. Начни с главы «Первые дни». Квадратные узлы ведут по основному пути, крупные шестиугольники отмечают вехи, а круглые узлы открывают дополнительные проекты. В заданиях по МЭ-сети, реактору и полётам есть ссылки на примеры. [Сверка с ТЗ до Марса](docs/AUDIT_0.8.1_RU.md)

Для игры нужны Minecraft 1.21.1, NeoForge 21.1.267, Java 21 и CurseForge. Выделенный сервер при новой установке создаёт мир `prototype_world`. Inventory Tweaks ReFoxed входит в клиентский профиль.

## Клиент — CurseForge

1. Распакуйте этот общий архив в отдельную папку, например `D:\Minecraft\M1-SciFi-Prototype-0.8.1`. **Вложенный ZIP из `client` передайте CurseForge целиком.**
2. В CurseForge откройте Minecraft → создание/импорт профиля → импорт из ZIP. Выберите `client/M1-SciFi-Prototype-0.8.1-CurseForge.zip` и дождитесь установки. Название кнопки зависит от языка приложения.
3. В настройках профиля задайте **8192 МБ RAM**. Это начальная настройка для ваших 32 ГБ, её ещё предстоит проверить под нагрузкой. Серверу отдельно выделено 5 ГБ.
4. Запустите профиль через CurseForge. Используйте Java 21; штатный подходящий runtime приложения подходит. Первый запуск может быть долгим.
5. На втором ПК импортируйте тот же ZIP с теми же версиями. Не добавляйте пока другие моды и шейдеры.

Импорт содержит 58 файлов CurseForge, мод совместимости и клиентский мод меню. FTB Backups 3 21.1.5 устанавливается и на клиент, и на выделенный сервер. Sodium, StellarView и карты Xaero входят только в клиент.

## Сервер — Windows 11

Откройте PowerShell в папке `server` распакованного комплекта. Прочитайте [Minecraft EULA](https://aka.ms/MinecraftEULA). Следующая команда устанавливает сервер и подтверждает ваше согласие с EULA:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Server.ps1 -AcceptEula
```

Скрипт ищет Java 21 в PATH, JAVA_HOME и стандартном runtime CurseForge. Если Java не нашлась, укажите путь явно:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Server.ps1 -AcceptEula -JavaPath 'C:\Path\To\Java21\bin\java.exe'
```

Можно переиспользовать уже скачанные моды профиля CurseForge, указав `-ClientModsPath 'D:\Path\To\CurseForgeProfile\mods'`: каждый файл всё равно сверяется по SHA-256; недостающие скачиваются отдельно.

После установки запустите `Start-Server.cmd` и дождитесь `Done (...)! For help, type "help"`. При необходимости передайте ему `-JavaPath 'C:\Path\To\Java21\bin\java.exe'` и/или `-MemoryGB 5`.

- На ПК с сервером подключайтесь к `localhost:25565`.
- В локальной сети второй игрок подключается к IPv4-адресу этого ПК и порту 25565. В брандмауэре разрешите входящий TCP 25565 для своей частной сети.
- Из другой сети нужен доступ к TCP 25565 через ваш обычный маршрут/NAT либо игровой VPN; это не настраивается комплектом.
- `online-mode=true`: нужны действующие игровые аккаунты. RCON выключен.
- Для остановки введите `stop` в консоли сервера. Не закрывайте окно во время сохранения.

Сервер устанавливается в `server/server`. Существующие конфиги при повторной установке сохраняются; папку с чужим сервером установщик не использует. Для переноса своего мира сначала остановите сервер и сохраните копию папки мира.

Если NeoForge остановился на скачивании библиотек с `Read timed out`, повторите установку в той же папке. Установщик повторно использует файлы с корректными контрольными суммами. Журнал NeoForge лежит рядом с `Install-Server.ps1` под именем `neoforge-21.1.267-installer.jar.log`. Запускайте сервер после строки `Installation complete`.

## Первая проверка

Войдите на сервер и откройте книгу FTB Quests через кнопку в инвентаре. Для общего журнала заданий соберите одну команду FTB Teams. Первая глава начинается с верстака, каменной кирки и печи. На вехе «Открытие электроники» возьмите награду исследования, чтобы сервер открыл рецепты для обоих игроков.

Администратор может проверить текущее состояние командой `m1probe` в консоли. Команды ручного закрытия и открытия приведены в `docs/TEST_PROTOCOL_RU.md`. Для прохождения главы пользуйтесь книжкой квестов и JEI.

Для доступа к Марсу завершите «Рабочую линию снабжения» в «Межпланетной логистике», чтобы открыть «Марсианскую базу». При сбое клиента или подключения пригодятся `logs/latest.log` клиента и `server/server/logs/latest.log` сервера.

## Обновление с 0.8.0

1. Закрой Minecraft и останови выделенный сервер командой `stop`. Сделай копию мира.
2. Распакуй `M1-SciFi-Patch-0.8.0-to-0.8.1.zip`. Скопируй из него папки `config` и `kubejs` в корень клиентского профиля CurseForge с объединением папок и заменой одноимённых файлов.
3. Если играешь на выделенном сервере, скопируй те же две папки в корень запущенной установки, где лежат `mods`, `server.properties` и мир. В стандартном комплекте это `server/server/`.
4. Запусти игру. В книге появится раздел «Земная мастерская» и глава «Первые дни». У старых заданий сохранились идентификаторы. Новые промежуточные задания можно пройти в существующем мире.

При обновлении из полного комплекта нужные папки находятся в `server/overrides/`. Скопируй `config/ftbquests/quests`, два файла `config/historystages/global/m1_proto_electronics.json` и `m1_first_space.json`, а также `kubejs/assets/immersivepetroleum` и `kubejs/data/m1prototype/recipe/openfm` с сохранением вложенных путей. Для чистого профиля импортируй полный клиентский ZIP через CurseForge.
