# M1 SciFi 1.0.0

В 1.0.0 игровые окна получили чёрно-оранжевую палитру, а названия сезонов стали объёмными. [Обновление с 0.11.1](docs/UPDATE_1.0.0_RU.md)

В 0.11.1 добавлены шейдеры, стальной интерфейс и обновлённые плашки сезонов. [Клиентский патч](docs/UPDATE_0.11.1_RU.md)

В 0.11.0 появились небольшие награды за квесты, Decocraft, новые эффекты и настройки мира. [Изменения и обновление](docs/UPDATE_0.11.0_RU.md)

В 0.10.0 после «Внеземного цеха» открывается «Автономная колония». Построй базу на Wolf 1069 b, обеспечь первую смену жителей и наладь связь с Землёй. В сборке тринадцать глав и 334 задания. Клавиша **0** возвращает обзор главы. [Обновление 0.10.0](docs/UPDATE_0.10.0_RU.md)

Для игры нужны Minecraft 1.21.1, NeoForge 21.1.267, Java 21 и CurseForge. Выделенный сервер при новой установке создаёт мир `prototype_world`. [Руководства по главам](docs/README.md)

CurseForge и установщик сервера скачивают сторонние моды в зафиксированных версиях. В архив входят собственные `m1packcompat-0.2.5.jar` для клиента и сервера и `m1packclient-0.5.2.jar` для клиента. Для установки нужен интернет. Используйте одинаковые версии модов на обоих клиентах и сервере.

## Клиент — CurseForge

1. Распакуйте общий архив в отдельную папку, например `D:\Minecraft\M1-SciFi-1.0.0`. **Вложенный ZIP из `client` передайте CurseForge целиком.**
2. В CurseForge откройте Minecraft → создание/импорт профиля → импорт из ZIP. Выберите `client/M1-SciFi-1.0.0-CurseForge.zip` и дождитесь установки. Название кнопки зависит от языка приложения.
3. При 32 ГБ RAM начните с **8192 МБ** для клиента и **5 ГБ** для сервера.
4. Запустите профиль через CurseForge на Java 21. При первом запуске загрузка занимает больше времени.
5. На втором ПК импортируйте тот же ZIP.

Импорт содержит 63 файла CurseForge, мод совместимости и клиентский мод меню. FTB Backups 3 21.1.5 устанавливается и на клиент, и на выделенный сервер. Sodium, Iris, Sildur’s Vibrant, LambDynamicLights, StellarView и карты Xaero входят только в клиент.

## Сервер — Windows 11

Откройте PowerShell в папке `server` распакованного комплекта. Параметр `-AcceptEula` подтверждает, что вы приняли [Minecraft EULA](https://aka.ms/MinecraftEULA).

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Server.ps1 -AcceptEula
```

Скрипт ищет Java 21 в PATH, JAVA_HOME и стандартном runtime CurseForge. Если Java не нашлась, укажите путь явно:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Server.ps1 -AcceptEula -JavaPath 'C:\Path\To\Java21\bin\java.exe'
```

Параметр `-ClientModsPath 'D:\Path\To\CurseForgeProfile\mods'` позволяет использовать уже скачанные файлы CurseForge. Установщик сверит их по SHA-256 и загрузит недостающие.

После установки запустите `Start-Server.cmd` и дождитесь `Done (...)! For help, type "help"`. При необходимости передайте ему `-JavaPath 'C:\Path\To\Java21\bin\java.exe'` и/или `-MemoryGB 5`.

- На ПК с сервером подключайтесь к `localhost:25565`.
- В локальной сети второй игрок подключается к IPv4-адресу этого ПК и порту 25565. В брандмауэре разрешите входящий TCP 25565 для своей частной сети.
- Из другой сети подключайтесь через настроенный проброс TCP 25565 или игровой VPN.
- Сервер с `online-mode=true` требует действующие игровые аккаунты. RCON выключен.
- Для остановки введите `stop` в консоли сервера. Не закрывайте окно во время сохранения.

Сервер устанавливается в `server/server`. Существующие конфиги при повторной установке сохраняются; папку с чужим сервером установщик не использует. Для переноса своего мира сначала остановите сервер и сохраните копию папки мира.

Если NeoForge остановился на скачивании библиотек с `Read timed out`, повторите установку в той же папке. Установщик повторно использует файлы с корректными контрольными суммами. Журнал NeoForge лежит рядом с `Install-Server.ps1` под именем `neoforge-21.1.267-installer.jar.log`. Запускайте сервер после строки `Installation complete`.

## Первый вход

Войдите на сервер, соберите одну команду FTB Teams и откройте книгу через кнопку в инвентаре. Первая глава начинается с верстака, каменной кирки и печи. На вехе «Открытие электроники» заберите командную награду, чтобы открыть соответствующие рецепты. При сбое подключения пригодятся `logs/latest.log` клиента и `server/server/logs/latest.log` сервера.
