# M1 SciFi

Индустриальная сборка для двух игроков на Minecraft Java 1.21.1, NeoForge 21.1.267 и Java 21. Основной путь ведёт от ранней металлургии до автономной колонии на Wolf 1069 b. В книге 13 глав и 334 задания. В **0.10.1** обновлено оформление клиента.

- [Обновление клиента с 0.10.0](docs/UPDATE_0.10.1_RU.md)
- [Руководства по игре и история выпусков](docs/README.md)
- [Статус сборки](docs/STATUS_RU.md)
- [Зафиксированные версии модов](docs/MODS.md)
- [Исходники и сборка архивов](SOURCE_RU.md)

Для новой установки используйте `M1-SciFi-Prototype-0.10.1.zip`. Для перехода с 0.10.0 есть `M1-SciFi-Patch-0.10.0-to-0.10.1.zip`. Архивы передаются отдельно. Репозиторий содержит исходники, конфигурацию и инструменты упаковки.
