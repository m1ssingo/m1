Для новой установки используйте клиентский профиль и серверный комплект из `M1-SciFi-Prototype-0.10.0.zip`. Для перехода с 0.9.0 есть отдельный патч.

Клиентский профиль содержит заставку v4 и `m1packclient-0.4.4.jar` с обзором главы. Локальная сборка описана в [инструкции к исходникам](SOURCE_RU.md).

Для повторной упаковки используйте `tools/build_release.py` и собственные JAR из комплекта 0.10.0.
