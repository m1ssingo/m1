# M1 SciFi

Индустриальная сборка для двух игроков на Minecraft Java 1.21.1, NeoForge 21.1.267 и Java 21. Основной путь ведёт от ранней металлургии до автономной колонии на Wolf 1069 b. В книге 13 глав и 334 задания. В **1.0.0** игровые окна получили чёрно-оранжевую палитру, а названия сезонов стали объёмными.

Для новой установки используйте `M1-SciFi-1.0.0.zip`. Для перехода с 0.11.1 используйте `M1-SciFi-Patch-0.11.1-to-1.0.0.zip`. Архивы передаются отдельно. В репозитории находятся исходники, конфигурация и инструменты упаковки.
