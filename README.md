Для новой установки используйте клиентский профиль и серверный комплект из `M1-SciFi-Prototype-0.8.3.zip`. Для перехода с 0.8.2 есть отдельный патч квестовой книги.

Клиентский профиль уже содержит заставку v4 и `m1packclient-0.4.3.jar`. Локальная сборка описана в [инструкции к исходникам](SOURCE_RU.md).

Для повторной упаковки используйте `tools/build_release.py` и оба собственных JAR из комплекта 0.8.3.
