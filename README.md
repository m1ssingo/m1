# M1 SciFi

Индустриальная сборка для двух игроков на Minecraft Java 1.21.1, NeoForge 21.1.267 и Java 21. В **0.10.0** основной путь ведёт от ранней металлургии до автономной колонии на Wolf 1069 b. В книге 13 глав и 334 задания.

- [Руководства по игре и история выпусков](docs/README.md)
- [Статус 0.10.0](docs/STATUS_RU.md)
- [Зафиксированные версии модов](docs/MODS.md)
- [Исходники и сборка архивов](SOURCE_RU.md)

Для новой установки используйте `M1-SciFi-Prototype-0.10.0.zip`. Для перехода с 0.9.0 есть `M1-SciFi-Patch-0.9.0-to-0.10.0.zip`. Архивы передаются отдельно. Репозиторий содержит исходники, конфигурацию и инструменты упаковки.
