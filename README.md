# M1 SciFi

Индустриальная сборка для двух игроков на Minecraft Java 1.21.1, NeoForge 21.1.267 и Java 21. Основной путь ведёт от ранней металлургии до автономной колонии на Wolf 1069 b. В книге 13 глав и 334 задания. В **0.11.0** добавлены награды, оформление базы и изменения игрового времени и клиента.

- [Руководства по игре и история выпусков](docs/README.md)
- [Статус сборки](docs/STATUS_RU.md)
- [Зафиксированные версии модов](docs/MODS.md)

Для новой установки используйте `M1-SciFi-Prototype-0.11.0.zip`. Для перехода с 0.10.2 используйте `M1-SciFi-Patch-0.10.2-to-0.11.0.zip`. Архивы передаются отдельно. Репозиторий содержит исходники, конфигурацию и инструменты упаковки.
