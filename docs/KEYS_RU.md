# Клавиши 0.3.0

Клавиши указаны по физическим позициям английской раскладки. Сочетания используют Alt. Переназначение выполняется при первом открытии главного меню и сохраняет пользовательские настройки. Сброс всех клавиш вручную после этого вернёт значения самих модов.

| Действие | Назначение |
|---|---|
| Рюкзак Sophisticated Backpacks | B |
| Создать точку Xaero | Insert |
| Экран Chunk Loaders | Home |
| Звёздная карта Deepfield | End |
| Книга FTB Quests | клавиша тильды / обратного апострофа (слева от 1) |
| Беспроводной терминал AE2 | Alt+E |
| Mekanism: режим шлема | Alt+V |
| Mekanism: режим нагрудника | Alt+G |
| Mekanism: режим поножей | Alt+J |
| Mekanism: режим ботинок | Alt+B |
| Mekanism: HUD | Alt+H |
| Mekanism: общий режим | Alt+N |
| NTM: калькулятор | Alt+C |
| NTM: HUD | Alt+U |
| NTM: магнит | Alt+M |
| Deepfield: режим инструмента | Alt+R |
| Deepfield: зависание инструмента | Alt+T |
| Deepfield: включение джетпака | Alt+K |
| Deepfield: зависание джетпака | Alt+I |
| Deepfield: HUD джетпака | Alt+L |
| Iron Jetpacks: двигатель | V |
| Iron Jetpacks: зависание | H |

Проверка выполнена по 238 зарегистрированным назначениям реального клиента. Убраны выбранные пересечения рюкзака, вейпоинта, общих экранов и режимов оборудования. Общие клавиши интерфейсов, транспортных средств и действий в разных контекстах сохранены. Наличие одинаковой клавиши в настройках само по себе ещё не означает одновременное срабатывание.

Отчёт последнего запуска находится в `config/m1pack-keybindings.json` внутри профиля. Если личное назначение совпало с новой клавишей другого действия, поменяйте удобное сочетание через «Настройки → Управление»; автоматическое применение повторно его не затронет.
