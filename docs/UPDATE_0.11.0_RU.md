# M1 SciFi 0.11.0

Выпуск для Minecraft 1.21.1 и NeoForge 21.1.267.

| Что изменилось | Как работает |
| --- | --- |
| Награды за задания | Добавлены 29 небольших наград. В четырёх заданиях выдаются два пузырька опыта. Памятные флаги, картины и торт выдаются один раз на команду. |
| Склад рядом с печью | Засчитывается железный сундук или «Улучшение сундука: С деревянного до железного». |
| Мины NTM | В новых чанках отключена отдельная генерация противопехотных мин. Мины в шаблонах построек сохранены. |
| Время | День и ночь идут в 1,5 раза дольше. Полные сутки занимают 30 минут при 20 TPS. |
| Сезоны | Serene Seasons показывает название сезона на экране при входе и при его смене в обычном мире. |
| Факел в руке | LambDynamicLights добавляет освещение вокруг игрока. Настройки спавна мобов используют обычный игровой свет. |
| Утилизация | Ищите в JEI «Мусорная корзина для предметов» из Trash Cans. |
| Оформление базы | Добавлен официальный Decocraft 3.0.11 для 1.21.1. |
| Рубка | Снят предел FallingTree на 100 брёвен и поднят до максимально допустимого предел сканирования. |
| Облака | Высота обычных облаков увеличена со 192 до 242 блоков. |
| Заставка | Струи выходят из трёх сопел. Убрана помеха в небе и сглажен ореол. Четыре заводские трубы выпускают движущийся дым. |
| Переходы | При загрузке территории и сохранении мира перед выходом используется размытая заставка сборки. |

## Обновление установленной сборки

Закройте клиент и остановите выделенный сервер. Распакуйте `M1-SciFi-Patch-0.10.2-to-0.11.0.zip` в отдельную папку. Из неё запустите PowerShell и передайте путь к папке с `mods` вашего профиля. Для выделенного сервера укажите внутреннюю папку сервера с `mods` и папкой мира.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update-Pack.ps1 -ClientPath 'D:\Minecraft\M1 SciFi Prototype'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update-Pack.ps1 -ServerPath 'D:\Minecraft\M1-Server\server'
```

Сценарий скачивает три мода с CurseForge для клиента и два для сервера, сверяет SHA-256 и помещает прежние файлы, которые он заменяет, в `m1-update-backups`. Для совместной игры обновите клиент и выделенный сервер. В одиночном профиле достаточно выполнить команду с `-ClientPath`.

Полный архив предназначен для новой установки. [Инструкция по импорту](../README_RU.md)
