# Межпланетная логистика

После «Вычислительной техники» в «Лунном форпосте» можно связать земную базу и лунную площадку. Совершенная схема управления, Titanium Plate и Moonglass Shard входят в рецепт ядра телепортации. Награда исследования открывает рецепты для всей команды на сервере.

## Монтаж линии

1. На два терминала нужны два телепорта и 18 блоков каркаса телепорта. Для ядер приготовь в сумме четыре Titanium Plate, четыре Moonglass Shard, две совершенные схемы управления и восемь жемчужин Эндера. Остальные детали смотри в JEI.
2. Собери на Земле вертикальную раму шириной три и высотой четыре блока. Поставь телепорт снизу по центру. Два блока прямо над ним оставь свободными. Подведи FE и создай частоту для этой пары.
3. Доставь второй комплект на Луну на Pathfinder. Собери такую же раму и выбери ту же частоту. Оставь свободный выход с обеих сторон. На время теста загрузку чанка может обеспечить напарник или один загрузчик. Подготовь запас заряда на каждом берегу.
4. Войди в земной портал, проверь прибытие и книгу квестов. На Луне выйди из проёма, затем войди снова для проверки обратного направления. Оба задания засчитываются при фактическом переходе через стационарный терминал Mekanism.

## Если терминал недоступен

| Признак | Что проверить |
|---|---|
| Рецепты скрыты | Общая награда «Исследование связи» получена после подготовки материалов |
| Терминал не распознаёт раму | Размеры 3×4, два свободных блока в центре, девять блоков каркаса телепорта |
| Пункт назначения недоступен | Совпадают имя и доступ к частоте, приёмник собран, его чанк загружен |
| Переход не срабатывает | Источник отправления накопил достаточно FE, маршрут доступен по этапу |
| Книга ждёт переход | Завершены задания обоих терминалов и выполнен переход с нужного берега |

## Побочные проекты

- Сравни резерв FE у обоих терминалов и выдели отдельный запас на кислород. Оставь Pathfinder и запас топлива на случай остановки линии.
- Для партии материалов проверь пару квантовых телепортов на отдельной частоте. Начни с нескольких обычных предметов и свободного выходного буфера.
- Для общего склада можно собрать квантовый мост AE2. Сверь форму и пару сингулярностей со справочником AE2. Оставь один основной контроллер и проверь каналы с обеих сторон.

Команды для проверки задания в тестовом мире есть в [протоколе](TEST_PROTOCOL_RU.md).
