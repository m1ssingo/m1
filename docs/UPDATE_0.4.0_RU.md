# Обновление 0.4.0

В книге теперь 43 задания. Из них 20 дополнительных и отмечены как необязательные. Первые две главы получили задачи по питанию, логистике, управлению производством и добыче. В химии можно параллельно развивать переработку и электронику. Третья глава «Тяжёлая промышленность» продолжает цепочку после химии.

Для обновления установленной 0.3.1 остановите сервер командой `stop` и сделайте копию мира. В распакованном архиве откройте `server/overrides/` и перенесите следующие папки с заменой одноимённых файлов в корень **установленного** сервера, обычно `server/server`.

- `config/ftbquests/quests/chapters/` содержит три главы.
- `kubejs/data/hbm/recipe/anvil_construction/` содержит два варианта рецепта первого сборочного станка.

Запустите сервер и откройте книгу. Для выделенного сервера клиент 0.3.1 подходит к 0.4.0. При игре в одиночном мире скопируйте те же две папки в каталог профиля CurseForge при закрытой игре. Этот каталог доступен через «Открыть папку» в профиле. Для новой установки используйте вложенный профиль 0.4.0 и установщик из `server/`.

На тестовой копии сохранения проверены старый прогресс, взятая награда и открытие новой главы после химии. Если вы вручную редактировали файлы двух старых глав, сохраните их отдельно перед заменой.
