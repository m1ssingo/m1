# M1 SciFi 0.8.5

**«NTM • Инженерный справочник»** открывается правой кнопкой мыши. Книга выдаётся за квест **«Стальная наковальня»**. Для изготовления на верстаке положи книгу и стальную пластину в две любые клетки.

В справочнике есть поиск, каталог оборудования с названиями из NTM, рецепты, цепочки руд и нефтепродуктов, подача HE, транспорт, автоматизация и диагностика. Послойные карты показывают точку установки, ядро, занятые клетки и порты. Они сняты с NTM Continuum 1.0.6, который используется в M1 SciFi.

Квест «От реактора до турбины» теперь принимает доступную в выживании **Промышленную паровую турбину** `hbm:machine_industrial_turbine`. Её рецепт есть в сборочной машине. После обновления уже выполненные задания сохраняют прежние идентификаторы.

## Установка патча

1. Закрой игру и останови выделенный сервер. Сохрани копию своего мира.
2. Объедини папки `config` и `kubejs` из архива патча с одноимёнными папками каждого профиля и установленного сервера с заменой совпадающих файлов. В стандартном комплекте установленный сервер находится в `server/server/`.
3. Войди в мир и открой справочник. Если награда уже была получена до обновления, книгу можно изготовить на верстаке.

Для новой установки используй полный архив 0.8.5. Патч предназначен для профиля и сервера 0.8.4.
