# Переход на 0.2.0

Для проверки главы с самого начала установите сервер из 0.2.0 в новую папку и импортируйте вложенный CurseForge ZIP отдельным профилем. В свежем мире электроника закрыта до квестовой награды.

Если нужно перенести тестовый мир из 0.1.1, сначала остановите оба сервера командой `stop`. Затем скопируйте целиком папку мира `prototype_world` из старого экземпляра `server\server` в новый. Новый сервер должен быть установлен и ещё не запущен. Можно скопировать `ops.json` и `whitelist.json`, если ими пользовались. Если имя мира менялось, укажите его в `level-name` нового `server.properties`. Запускайте только один сервер на порту 25565.

Прогресс демонстрационного этапа `m1_proto_electronics` переедет вместе с миром. Если этап уже открывали, в перенесённом мире он будет открыт и в 0.2.0. Для отдельной проверки квестовой награды на копии мира закройте его командой `history global lock m1_proto_electronics` в серверной консоли. Игроков, которые вышли из сохранённого мира в творческом режиме, можно вернуть в выживание командой `gamemode survival ИМЯ`.

У обоих игроков используйте профиль 0.2.0. В составе есть `m1packcompat-0.2.0.jar`, моды и файлы главы. Профиль 0.1.1 и старый сервер пригодятся для возвращения к предыдущей версии.
