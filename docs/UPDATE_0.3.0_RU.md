# Обновление 0.3.0 — без спойлеров

Добавлены фон из присланной картинки, музыка Ignition и стальные кнопки с тёплой оранжевой подсветкой в главном меню. Громкость регулируется ползунком «Музыка». Картинка сохраняет пропорции и встроенный логотип. Оформление действует на главном экране; игровые меню пока используют штатный интерфейс.

Следующая производственная глава продолжает существующую цепочку. Подсказки находятся в квестах. Версии сторонних модов сохранены. Название будущего перехода к космосу закреплено: «От грязи к звездам».

Проверены зарегистрированные клиентом клавиши. Для 19 действий подготовлены новые назначения; основные приведены в `KEYS_RU.md`. Они применяются один раз только к назначениям, оставленным по умолчанию. Ваши изменённые клавиши сохраняются. После этого новые назначения можно менять обычным способом в настройках.

## Обновление действующего сервера и профилей 0.2.0

Новый мир создавать не нужно. Перед заменой файлов остановите сервер командой `stop` и закройте игру на обоих ПК. Сохраните копию папки мира и текущих конфигов.

1. Распакуйте общий архив 0.3.0. В его `source/overrides/` находятся общие файлы обновления. Скопируйте содержимое этой папки с заменой в корень **установленного** сервера (обычно `server/server`) и в корень каждого профиля CurseForge через «Открыть папку».
2. Только на обоих клиентах скопируйте содержимое `source/client-overrides/` в корень профиля. В `mods` появится `m1packclient-0.3.0.jar`. На выделенный сервер этот файл не нужен. `m1packcompat-0.2.0.jar` остаётся: версия его исправления не менялась.
3. Запустите сервер, затем оба клиента. Мир, инвентари, исследования и прогресс квестов остаются на месте; добавляется новая глава. Собранный набор не заменяет `options.txt` и файлы мира.

Эта инструкция рассчитана на 0.2.0 без собственных изменений в поставляемых рецептах и квестах. Если вы их редактировали, сравните изменённые файлы перед заменой. Переустановка через старый `Install-Server.ps1` не обновляет уже существующие конфиги, поэтому используйте копирование выше.

## Установка отдельным профилем

Можно импортировать вложенный `client/M1-SciFi-Prototype-0.3.0-CurseForge.zip` как новый профиль. Сервер устанавливается по общему `README_RU.md`. Для переноса мира остановите оба сервера, скопируйте **всю** папку мира в новый экземпляр и проверьте `level-name` в `server.properties`. Установленное имя по умолчанию — `prototype_world`. Одновременно запускайте один сервер на порту 25565.

## Выборочная проверка

Достаточно обычной игры. По желанию посмотрите новое меню, настройку громкости и действия на B, Insert и клавише `~`. Полный протокол повторять не требуется. Если встретится ошибка, пригодятся описание действия и `logs/latest.log`; при сбое подключения — также серверный журнал.

Графический клиент с модами запущен в тестовом окружении: отображение меню, открытие настроек и запуск аудиодорожки подтверждены. Физическое звучание на Windows, реальное подключение двух игроков и прохождение новой главы в выживании здесь не проверялись.
