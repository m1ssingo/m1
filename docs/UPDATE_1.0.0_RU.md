# M1 SciFi 1.0.0

Первый стабильный выпуск для Minecraft 1.21.1, NeoForge 21.1.267 и Java 21.

- Названия сезонов получили объёмные грани, контур и мягкую тень. Плашки доступны на русском и английском.
- Хотбар, инвентарь, окна крафта и хранения, книга рецептов, JEI, кнопки и подсказки используют чёрно-оранжевую палитру.
- Восстановлена загрузка русского перевода Immersive Petroleum.
- Главное меню показывает версию сборки, а новый выделенный сервер отображается в списке как M1 SciFi.

## Обновление с 0.11.1

Закройте игру, распакуйте `M1-SciFi-Patch-0.11.1-to-1.0.0.zip` и выполните команду из папки патча. Передайте в `-ClientPath` папку существующего профиля CurseForge.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update-Pack.ps1 -ClientPath 'D:\Minecraft\M1 SciFi Prototype'
```

Патч заменяет `m1packclient` и сохраняет предыдущий JAR в `m1-update-backups`. Проведите обновление на обоих клиентах. Для совместной игры подходит выделенный сервер 0.11.1.

Для новой установки используйте [инструкцию для полного архива](../README_RU.md).
