# Исправление 0.3.1

При подключении Authlib может получить HTML от службы сессий Minecraft. Раньше длинный текст страницы растягивал экран ошибки. Теперь клиент показывает штатное сообщение о недоступности серверов аутентификации и кнопку возврата. При таком сообщении повторите вход, когда служба снова ответит. Проверка сессии продолжает действовать.

Если у вас уже 0.3.0, закройте игру и откройте папку профиля в CurseForge. В `mods` замените `m1packclient-0.3.0.jar` на `m1packclient-0.3.1.jar` из `source/client-overrides/mods/` этого комплекта. В папке должен остаться один JAR мода меню.

Для перехода с 0.2.0 используйте порядок копирования из `UPDATE_0.3.0_RU.md` и файлы из этого комплекта. Клиентский JAR и вложенный ZIP для импорта в нём имеют версию 0.3.1.
