# Исправление вылета при подключении: 0.1.0 → 0.1.1

Причина подтверждена присланными журналами: FTB Backups 3 21.1.5 находился на сервере, но отсутствовал в клиенте. При начале резервного копирования сервер пытался отправить пакет `ftbbackups3:backup_progress`; NeoForge отклонял отправку и завершал сервер с `UnsupportedOperationException`.

Для этой версии FTB Backups 3 требуется установка на обе стороны. Это также прямо указано в [официальной документации для Minecraft 1.21.1](https://docs.feed-the-beast.com/mod-docs/1.21.1/mods/suite/Backups-3/).

## Как починить уже установленный профиль

1. Полностью закройте игру. Убедитесь, что сервер остановлен.
2. Откройте `D:\Minecraft\M1-Prototype\server\server\mods`. Скопируйте оттуда **`ftb-backups-3-21.1.5.jar`**. Используйте именно копирование: файл должен остаться и на сервере.
3. В CurseForge откройте меню установленного профиля → **Open Folder / Открыть папку**. Вложите JAR в папку `mods` этого профиля. Убедитесь, что там нет второй версии FTB Backups 3. Остальные FTB-моды оставьте на месте.
4. Повторите добавление файла в клиентский профиль второго игрока до его подключения.
5. Запустите сервер обычным `Start-Server.cmd`, затем игру. Подключитесь к прежнему миру.

Если файла под рукой нет, скачайте [точный файл 21.1.5 для NeoForge 1.21.1](https://www.curseforge.com/minecraft/mc-mods/ftb-backups-3/files/8078605). Его SHA-256:

```text
b769eb27e8a26c8a894d87ae0bea5c544ebb3ef6712af2f79cd6ef16afe685d4
```

**Мир не удаляйте и не пересоздавайте.** Переустановка сервера, изменение конфигурации и повторный импорт всего профиля для этого исправления не требуются. Резервное копирование остаётся включённым.

## Что проверить

- Оба игрока подключаются и остаются на сервере после запуска резервного копирования.
- В журнале нет повторного `Payload ftbbackups3:backup_progress may not be sent to the client!`.
- Клиент больше не пишет `received unknown config name ftbbackups3-server`.
- Можно выйти, снова зайти и штатно остановить сервер командой `stop`.

Вход после исправления ещё нужно проверить на вашем ПК. Само исправление состава проверено: новый импорт содержит FTB Backups 3 с теми же file ID и SHA-256, что и сервер; остальные моды и настройки не обновлялись.

## Для новой установки

В общем комплекте 0.1.1 используйте `client/M1-SciFi-Prototype-0.1.1-CurseForge.zip`. В него FTB Backups 3 уже включён. Если текущий профиль исправлен копированием JAR, новый профиль создавать не нужно.
