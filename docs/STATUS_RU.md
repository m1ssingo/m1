# M1 SciFi Prototype 0.4.0

Сервер 0.4.0 загружает 43 задания в трёх главах. Из них 20 дополнительных. Проверены две команды с прогрессом от 0.3.1, параллельное начало переработки и электроники, открытие мастерской NTM после завершения химии и прохождение обязательных вех при открытых дополнительных задачах. Проверен рецепт первой сборочной машины NTM в таблице стальной наковальни. Полное прохождение в выживании ещё предстоит.

В 0.3.1 проверен вход на выделенный тестовый сервер с включённой проверкой сессий. Локальная имитация службы сессий вернула HTTP 503 с HTML. Клиент показал короткое сообщение об ошибке входа и кнопку «К списку серверов». Для остальных строк ниже приведены результаты проверок 0.3.0, на которой основан выпуск.

В 0.3.0 появились оформление главного меню, музыка Ignition, одноразовая настройка клавиш по умолчанию и первая редакция химической главы. Порядок обновления до 0.4.0 находится в `UPDATE_0.4.0_RU.md`.

## Проверено

| Область | Результат |
|---|---|
| Графический клиент | Реальный клиент NeoForge со всеми клиентскими модами открыл новое меню, экраны настроек и звука. Скриншот — `menu-preview.png` |
| Музыка | Vorbis-дорожка принята звуковым движком; MusicManager подтвердил воспроизведение. Использован программный аудиовыход без физических колонок |
| Клавиши | Прочитаны 238 назначений, применены 19 изменений в чистом профиле. На повторном запуске настройки сохранились, повторных изменений нет |
| Сервер и квесты | На 0.4.0 загружаются три главы и 50 задач на получение конкретных предметов. Квестовая награда первой главы открывает этап от имени тестового игрока |
| Рецепты | На 0.4.0 стальная наковальня NTM загружает новый рецепт первого сборочного станка с двумя продвинутыми схемами Mekanism. Сепаратор и рецепты AE2 прошли повторную проверку |
| Блокировка обработки | Повторена проверка обычного наполнителя и фабрики: закрытие этапа останавливает выпуск базовых схем, сырьё сохраняется; открытие возобновляет работу. Обычный рецепт сплава продолжает работать |
| Упаковка | Клиентский мод меню включён только в клиентский импорт. Сервер получает общий мод совместимости. Сторонние версии и контрольные суммы сохранены |

Сырые результаты и выдержки журналов приложены в `evidence/`. Серверные проверки выполняются на отдельном одноразовом мире Linux с Java 21; графический клиент — с программным рендерером. Подключение реальных аккаунтов, Windows-скрипты, звучание через физический аудиовыход и прохождение новой главы в выживании в этом окружении не проверены. Запрос публичного ключа Yggdrasil недоступен для тестового процесса; это не помешало запуску и сохранению мира.

Проверки сохранения этапа после перезапуска и `/reload` относятся к предыдущему прогону 0.2.0 с тем же общим модом совместимости. Они включены как базовая проверка; новый серверный прогон 0.3.0 отдельно подтверждает главы, рецепты и обработку.

## Дальнейшая разработка

Полная прогрессия и справочники ещё разрабатываются. Третья глава доводит игрока до мастерской NTM и проверки рабочей площадки. Следующие задачи — первая ядерная установка, связь с подготовкой к космосу, настройка энергетики и проверка ограничения аварий одним чанком. Сейчас реакторы сохраняют штатное поведение своих модов. Переход к космическому этапу будет называться «От грязи к звездам».

Незавершённые проверки: уже запущенные задания автокрафта AE2 при закрытии этапа, все способы использования заблокированных предметов, полёты и работа реакторов. Назначения транспортных средств и оборудования ещё можно уточнять по обычной игре. Повторять весь ручной протокол для этой версии не требуется.
