# M1 SciFi 0.10.0

Это принятая версия для совместной игры. [Статус и результаты проверок](STATUS_RU.md)

После **«Внеземного цеха»** открывается **«Автономная колония»**. В главе 23 новых задания. Они ведут от первого рейса на Wolf 1069 b до работающей базы со своим питанием, воздухом, продовольствием, мастерской и связью с Землёй.

Первую смену подтверждает Colony Core. Когда заселятся двое жителей и появится добыча, присядь и нажми по ядру ПКМ пустой рукой. Для связи с Землёй после первой посадки возьми общую награду «Разрешение на связь с колонией».

## Патч для 0.9.0

Распакуй `M1-SciFi-Patch-0.9.0-to-0.10.0.zip`.

1. Закрой игру и останови сервер. Сохрани копию мира.
2. В папке `mods` клиента и работающего сервера убери `m1packcompat-0.2.3.jar`.
3. Объедини `config`, `kubejs` и `mods` из патча с одноимёнными папками каждого профиля и установленного сервера с заменой совпадающих файлов. В стандартном комплекте папка работающего сервера находится в `server/server/`.
4. Запусти сервер и клиенты. Для новой установки используй полный архив 0.10.0.

Если повторно запускаешь установщик сервера из комплекта 0.9.0, перенеси `server-kit/mods.lock.json` из патча рядом с `Install-Server.ps1`. В папке `overrides` этого комплекта обнови теми же файлами `config`, `kubejs` и `mods`, убрав старый JAR совместимости также из `overrides/mods`.

Подготовка рейса и устройство базы описаны в [руководстве по колонии](WOLF_COLONY_RU.md).
