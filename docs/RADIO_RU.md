# OpenFM: радио для прототипа

Установлен `openfm-neoforge-1.21.1-0.0.4.jar`. В творческом режиме найдите блок OpenFM в JEI, поставьте его и укажите прямой URL потока через интерфейс блока. Сайт станции вместо прямого URL не подходит. Поведение интерфейса и звук в игре ещё проверяются на клиенте.

| Станция | URL |
|---|---|
| Record | https://radiorecord.hostingradio.ru/rr_main96.aacp |
| Liquid Funk | https://radiorecord.hostingradio.ru/liquidfunk96.aacp |

Оба адреса получены из [официального API Radio Record](https://www.radiorecord.ru/api/stations/). Здесь проверены HTTP 200 и декодирование аудиосэмпла фактическим AAC-декодером установленного OpenFM: 44,1 кГц, два канала. Результаты находятся в `evidence/radio-decoder-results.json`.

Это подтверждает доступность потока и поддержку кодека в момент проверки. Пространственный звук, громкость, воспроизведение на двух клиентах и доступность потоков из вашей сети ещё не проверены. Если URL изменится, новый адрес можно получить у станции.

Spotify в прототип не интегрирован; этот необязательный пункт отложен.
