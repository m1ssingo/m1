# Радио OpenFM в M1 SciFi 0.10.0

Забери награду «Открытие электроники» и изготовь OpenFM Radio, Speaker и Tuner по рецептам JEI. Поставь оба блока. Тюнером нажми сначала на колонку, затем на радио. В интерфейсе радио укажи прямой адрес аудиопотока. Memory Card доступна после того же исследования.

| Станция | URL |
|---|---|
| Record | https://radiorecord.hostingradio.ru/rr_main96.aacp |
| Liquid Funk | https://radiorecord.hostingradio.ru/liquidfunk96.aacp |

На раннем стенде оба потока отвечали по HTTP и декодировались в AAC на 44,1 кГц с двумя каналами. Если поток перестал открываться, возьми свежий адрес из [официального API Radio Record](https://www.radiorecord.ru/api/stations/).
