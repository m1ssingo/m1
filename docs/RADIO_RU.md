# OpenFM: радио для прототипа

В версии 0.8.1 забери награду «Открытие электроники» и изготовь OpenFM Radio, Speaker и Tuner по рецептам JEI. Поставь оба блока. Тюнером нажми сначала на колонку, затем на радио. В интерфейсе радио укажи прямой адрес аудиопотока. Memory Card тоже изготавливается после открытия электроники.

| Станция | URL |
|---|---|
| Record | https://radiorecord.hostingradio.ru/rr_main96.aacp |
| Liquid Funk | https://radiorecord.hostingradio.ru/liquidfunk96.aacp |

Оба адреса получены из [официального API Radio Record](https://www.radiorecord.ru/api/stations/). Здесь проверены HTTP 200 и декодирование аудиосэмпла фактическим AAC-декодером установленного OpenFM: 44,1 кГц, два канала. Проверка декодирования относится к раннему прототипу.

Это подтверждает доступность потока и поддержку кодека в момент проверки. Пространственный звук, громкость, воспроизведение на двух клиентах и доступность потоков из вашей сети ещё не проверены. Если URL изменится, новый адрес можно получить у станции.

Spotify в прототип не интегрирован; этот необязательный пункт отложен.
